# Pickaxe King Auto

自動化《Pickaxe King Island》（Android `com.rogueuniongames.pickaxekingisland`）的素材採集。
透過 adb 控制手機、以 OpenCV 判斷畫面：截圖 → 判斷 → 點擊／滑動。

第一階段目標：「缺木頭」——自動導航到木材點（起始之地、小村莊為主）採集；
後續再擴充成整套自動刷流程。

## 現況（2026-10-18）

- 裝置：Samsung SM-S9360（Android 16），USB，`adb devices` = `R5GL15085ZJ`。
- 已驗證：
  - 截圖 `adb exec-out screencap -p`，約 0.7 秒／張（1440×3120）。
  - `adb shell input tap` 可送達 Unity 遊戲（點小屋會跳出「在小屋裡休息！」對話框）。
  - **移動＝按住拖曳**：拖曳方向＝角色行進方向；拖 0.9 秒 ≈ 世界位移 400–440 px；
    上／下／左／右四個方向量測一致。單純點一下、原地長按 1.5 秒皆不會移動。
  - 無輸入時位移量測為 (0, 0)（response > 0.6），可作為移動偵測基準（相位相關，見 `tests/`）。
  - 同一輸入連續兩次有位移、第三次變 0：是撞到地形／水域／地圖邊界，不是輸入失效。
- 待確認：
  - 小村莊相對目前位置的方向與距離。
  - 樹木／木材在畫面上的自動辨識方式（白色瞄準框、樹木模板比對）。

## 遊戲事實（使用者確認，2026-10-18）

- 玩家：拿鎬子的人物；鏡頭跟隨，固定停在畫面 **(720, 1400)**（水平置中、垂直中央偏上）。
  帽子／服裝會換、可能被場景物件遮住 → **認主角以畫面位置為主**，鎬子當輔助特徵。
- 目前位置：起始之地（木頭主要產地）；另一個木材點是「小村莊」。
- 砍伐：走到目標附近就會自動砍，目標周圍會出現 **4 個白色瞄準框**（可當砍伐中的偵測訊號）。
- 彈窗只有「點擊」才會出現；單純移動不會產生彈窗。
- **白色 4 角框＝可互動提示**（不是「可砍」專屬）：樹、石頭會出現；NPC、帳篷、商店、鍋爐等固定物
  也會出現，但走過去不會揮砍。
- **砍伐機制**（2026-10-18 使用者確認）：
  - 走進攻擊範圍就自動揮砍；**樹與石頭都是一下（1 hit）就砍掉**，一次揮鎬約 **0.2 秒**。
  - 命中會出現**揮鎬傷害數字**（目前固定 **151**）→ 本專案用它當命中判定：
    範本 `captures/tpl_dmg151.png`，比對分數 >0.72 視為命中（實測命中時 0.94–1.00）。
  - 「木材 x N」掉落提示**不可**當判斷依據：有掉落但沒吸到就不會顯示。
  - 左側「木材儲存庫」（例 8/118）是**掛機累積**，與手動砍木頭無關；點開可按左邊「領取」、
    再按下方叉叉關閉。
- **生成規則**：樹／石頭在**整個森林區隨機**生成（非固定點），砍掉後約 **100 秒**長回來；
  樹和石頭共用同一批生成位置，只是機率不同。
- 之後的生物（怪物）另有處理方式；農作物可以貼著砍，樹/石頭要「撞進去」。
- 帳篷：HP 不為 0 時不要按「在小屋裡休息」；休息時主角會消失、左右工具列隱藏，
  約 3–5 秒後自動醒來（醒來才可移動）。

## 自動砍素材進度（2026-10-18）

命中判定：比對傷害數字範本 `captures/tpl_dmg151.png`（>0.72 視為命中）。

| 版本 | 策略 | 結果 |
|---|---|---|
| v5 | 撞到就站著等樹消失 | 86 步 / 0 命中（判定誤導） |
| v6 | 改用傷害數字判定 | 56 步 / 2 命中 |
| v7 | 大步走＋撞住側滑 | 64 步 / 1 命中 |
| v9 | **每步重選方向＋走不動的方向進黑名單** | 154 步 / **7 命中**（有效區命中間隔 2.5–7 秒） |

已知問題：
- **沒有地區界線**：巡邏會往北走出起始之地（實測走到松露島，該區是岩石／黃金礦地形）。
  需要「地區判斷」（例：畫面看得到帳篷／商店／雞舍才視為在起始之地，否則往回走）。

## 快速開始

```bash
# 一次性：建立環境（已建立則略過）
python313 -m venv .venv && .venv\Scripts\python.exe -m pip install -r requirements.txt

# 截圖
.venv\Scripts\python.exe pk.py shot
# 點擊／滑動
.venv\Scripts\python.exe pk.py tap 720 1700
.venv\Scripts\python.exe pk.py swipe 720 1900 720 1500 800
# 目前前景 App
.venv\Scripts\python.exe pk.py app
# 量測兩張截圖之間的世界位移
.venv\Scripts\python.exe pk.py scroll captures/a.png captures/b.png

# 測試
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

## 結構

```
pkauto/adb.py      adb 控制層（截圖／點擊／滑動／按鍵）
pkauto/vision.py   影像工具（世界位移、模板比對、區域裁切）
pk.py              CLI 入口
tests/             合成影像單元測試（不需裝置）
captures/          執行時截圖（不進版控）
```
