# Pickaxe King Auto

自動化《Pickaxe King Island》（Android `com.rogueuniongames.pickaxekingisland`）的素材採集。

**目前的作法是純機械化固定流程**：不偵測畫面、不判斷該砍哪棵樹，
固定座標傳送、固定步數走路，走過去遊戲就會自動揮鎬。

## 一輪流程（實測 82 秒工作 + 30 秒等待 = 112 秒）

```
1. 點傳送石 (1340,1670)
2. 選單手指往上滑 500ms（內容上移 416px，避免以後上方新增地區時位置跑掉）
3. 點小村莊 (330,1464)
4. 往北 3 步
5. 掃描：左1 北1 右2 南1（每步 300px，按住 983ms）
6. 點傳送石 → 滑 → 點起始之地 (720,1434)
7. 往北 2 步（正好走到帳篷）
8. 點 (721,1839) 休息，等 3.2 秒
9. 掃描：左1 北1 右2 南1
10. 等 30 秒（樹約 100 秒重生，一輪 112 秒剛好）
```

## 執行

**雙擊 `start_auto.bat` 就會開始跑**（手機插著、遊戲開著即可）。
要停止：在那個視窗按 Ctrl+C。

命令列用法：

```bash
P=./.venv/Scripts/python.exe
$P cycle_fixed.py --minutes 240          # 跑 4 小時（預設最後等 30 秒）
$P cycle_fixed.py --dry-run              # 只印流程，不動手機
$P cycle_fixed.py --minutes 5 --wait 20  # 自訂等待秒數
```

`start_auto.bat` 是**純 ASCII**：命令提示字元解析 .bat 時若遇到中文（尤其 UTF-8 多
位元組）會把 echo 行拆成亂七八糟的指令，實測會出現「'結束（錯誤碼' 不是內部或外部
命令」。中文一律留給 Python 輸出（那是執行期 stdout，cmd 不會拿去解析）。

## 設計原則（踩過的坑換來的）

- **走過去就會自動砍**，所以不需要「找樹」→ 只需要穩定的走路路線。
- 移動是**搖桿式**：距離取決於「按住多久」，不是拖曳長度。
  里程模型 `px = 346 × 按住秒` → 300px ≈ 按住 867ms（同場實測：2809ms→978px、847ms→291px，
  兩點都是 ≈346px/秒、沒有起步延遲）。
  路線一律用 px 描述，換算集中在 `cycle_fixed.py::hold_ms()`（調參只改 `ROUTES` 的 px）。
  只走某幾段就用 `run_leg.py village 1 2 --template`，不必每次跑整輪。
- 傳送石**位置會浮動且有冷卻**，但實測 (1340,1670) 命中分數 1.00 → 固定點擊即可。
- 選單格子會慣性滑動 → 先做一次固定滑動把列表歸位，格子位置就固定。
- 休息對話框固定在 (721,1839)（起始之地往北 2 步後）→ 直接點，不需偵測。
- 不要點畫面上「很大一塊白色」的東西（那是彈窗/黑市），休息框例外且位置固定。
- 背景程序要殺乾淨：Hermes 的 process kill 只殺外層，python 子程序會活著。
  用 `Get-CimInstance Win32_Process | Where CommandLine -like '*cycle_fixed*'` 確認。

## 遊戲事實（使用者確認）

- 角色固定在畫面 **(720,1400)**；畫面跟著角色移動。
- **走過去就會自動揮鎬**；樹與石頭一下就砍掉，揮鎬約 0.2 秒。
- 樹／石頭在生成範圍內隨機長，砍掉後約 **100 秒**重生。
- **小村莊與起始之地都要往北走**才會到可砍的樹；往南是牛的農場（沒有樹）。
- 可以穿越：樹、石頭、NPC、人物、生物。不能穿越：建築物、河水、黃金樹。
- 小村莊有**黃金樹**（金色）不能砍，且會擋住後面的樹與角色。
- 生命值＝上方紅色條（數字/數字）；**歸零前要回帳篷休息**（起始之地北 2 步）。
- 傳送石＝右側藍色愛心，點開是 18 區的地區選單。

## 結構

```
cycle_fixed.py      唯一主程式：固定座標傳送 + 固定步數路線 + 固定休息
pkauto/adb.py       adb 控制層（截圖／點擊／swipe／按鍵）
pkauto/vision.py    影像工具（只用來量位移，不做物件偵測）
pk.py               CLI 小工具（shot/tap/swipe/app/scroll）
tests/              合成影像單元測試（不需裝置）
captures/           執行時 log（不進版控）
```
